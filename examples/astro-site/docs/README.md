# Kvarngatans Bageri docs

This folder is the site's memory: the hard rules, how to run it, settled
decisions and today's status. Read `hard-rules.md` and
`status/current-status.md` before starting real work. It's a light vault:
no dated progress log.

## Layout

- **`hard-rules.md`**: the enforced rules.
- **`running.md`**: how to install, run, build, check and deploy.
- **`quality-targets.md`**: the SEO, accessibility and performance bar.
- **`setup.md`**: the answers this setup was generated from.
- **`decisions/`**: numbered records of calls that rule out an alternative.
- **`status/current-status.md`**: what is true right now.
- **`status/open-questions.md`**: what is still undecided.
- **`status/todo.md`**: open work, as a checklist.
- **`design/`**: brand, typography and page structure.

## Maintenance

After a real chunk of work, update `status/current-status.md` if what's
true changed, tick or add lines in `status/todo.md`, and add a decision if
something was settled.
