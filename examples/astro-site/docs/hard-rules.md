# Hard rules

- **Everything visitors see is Swedish**, including alt text, meta titles
  and descriptions, form errors and the 404 page.
- **No em dashes** in code, docs or site text.
- **Opening hours, prices and the week's bread live in `src/data/`**, never
  hardcoded in a page or component, so they're changed in one place.
- **Ask before every push**: a push to `main` deploys the site.
