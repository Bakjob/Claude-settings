# Decisions

Numbered, permanent records of calls about Ember Hollow that rule out an
alternative. Never renumber or delete a file. If a decision is reversed, add
a new numbered file and point the old one's `Status` line at it.

## Template

```markdown
# NNNN: Short title

**Status:** Active (or: Superseded by [0007](./0007-slug.md))

**Decision:** One or two sentences: what is now true.

**Why:** The actual reasons. Name the concrete case that prompted it.

**Rules out:** What this forecloses.

**See also:** Related decisions or a fuller writeup elsewhere in the vault.
```
