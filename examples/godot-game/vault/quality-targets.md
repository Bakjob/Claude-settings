# Quality targets

## Performance

- **Platforms:** Windows and Linux PC, plus a web build for the itch.io page.
- **Minimum spec:** a 2018 laptop with integrated graphics.
- **Frame rate:** 60 FPS on the minimum spec, so a 16.7 ms frame budget.
- **Memory budget:** not set yet.
- **Load time:** not set yet.

## Accessibility

- **Tier:** Basic (Game Accessibility Guidelines): remappable controls,
  subtitles for all speech, no information by color alone, toggles for
  screen shake and flashing effects, pause anywhere.
- **Platform requirements:** none yet (no console release planned).
